ZeroG vs. Open-Source Antigravity Remotes

Short answer: Google Antigravity has no official mobile app, so two kinds of tools have emerged to fill the gap: dedicated companion apps like ZeroG, and community open-source projects that mirror your Antigravity session to a phone browser. Both connect to the same running desktop session — they differ mainly in setup effort, cost, and how they reach you outside your home network.

How open-source Antigravity remotes work

Several community projects exist that bridge Antigravity to a mobile browser over your local network. They're free and self-hosted. Setting one up typically means cloning a repository, running a local server or terminal commands, and — if you want access away from your home Wi-Fi — arranging a tunnel (for example ngrok, Tailscale or a Cloudflare Tunnel). Some projects have made this easier than others: a few now set the tunnel up for you in one click, while others still expect you to configure it yourself. Feature sets vary from project to project and change as maintainers update them, so check each project's own repository for current capabilities before relying on one.

How ZeroG works

ZeroG is a dedicated iPhone app built specifically for Antigravity. You install the ZeroG extension in Antigravity, pair your phone by scanning a QR code, and you're connected — no repository to clone, no server to run, no tunnel to configure. It connects over Wi-Fi or cellular through an encrypted relay, and your code and AI model stay on your own machine the whole time.

FAQ

Are there free or open-source alternatives to ZeroG?

Yes. Several community, open-source projects mirror an Antigravity session to a phone browser over your local network. They're free and self-hosted, but typically require cloning a repository, running your own server or terminal commands, and setting up a tunnel yourself for access beyond your home Wi-Fi.

Is ZeroG open source?

No. ZeroG is a closed-source commercial app distributed through the App Store. It's free to use with ads and one paired device; ZeroG Pro ($12.99/month; first month $8.99) removes ads and adds unlimited paired devices.

Which should I use, ZeroG or an open-source remote?

If you're comfortable running your own server, configuring a tunnel, and maintaining the setup yourself, an open-source remote can work well and costs nothing. If you want a working setup in about a minute that also connects over cellular without any tunnel configuration, ZeroG is built for that.
